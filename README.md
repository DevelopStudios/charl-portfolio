## Stack

Vanilla HTML, CSS, and JavaScript — no framework, no build step. Hosted on Kinsta.

To run it locally:

```sh
python3 -m http.server 4310
```

Then open <http://localhost:4310>.

The live build runs Angular and Nx against a Python/FastAPI backend on NVIDIA NIM, so document
text and questions leave the device. It is invite-only; access is requested from the sign-in
page. The earlier fully in-browser path (Transformers.js embeddings, WebLLM on WebGPU, one
SharedWorker model across tabs) is kept in the repository but is not part of the shipped app.
Its screenshot on the site (`assets/doclocal-nim-demo.png`) is the real UI, captured from a
mock-backed replay over a synthetic PDF.
